# Kitchyn v2 — agreed feature sequence

Confirmed by the user on 2026-09-06. Preserve this implementation order unless the user changes it.

1. **Merchant-created payment links.** A merchant builds an order and shares its checkout link, particularly for WhatsApp enquiries. The customer confirms missing details and pays; the paid order enters the existing fulfilment workflow.
2. **Meal-specific buying links.** A merchant shares a link to an individual meal so customers can go directly from a promotion to selecting its options and buying it.
3. **Send someone food.** A customer buys food for another person, with a recipient flow for confirming delivery details. Delivery fees, payment timing, and recipient coordination require design before implementation.

This records the agreed roadmap, not authorization to start implementation. Detailed requirements remain to be worked out. Group ordering and the earlier broader feature suggestions are not part of this agreed sequence.
